# 📊 AI-Powered Retail Analytics & Business Intelligence Dashboard

An interactive retail analytics dashboard built using Python, Streamlit, Plotly, and Prophet to analyze sales trends, customer behavior, regional performance, and business insights.

---

# 🚀 Project Overview

Retail businesses generate large amounts of transactional data, but extracting actionable insights manually is difficult.

This project provides:
- Business analytics
- Interactive visualizations
- Product performance analysis
- Regional sales analysis
- Return-rate tracking
- Promotion effectiveness insights
- Sales forecasting using Prophet

The dashboard helps businesses make data-driven decisions through automated insights and KPI monitoring.

---

# 🔥 Features

## 📈 Analytics
- Weekly revenue trend analysis
- Product-wise revenue tracking
- Regional performance analysis
- Store performance monitoring

## 🧠 Business Intelligence
- Top-performing product detection
- Underperforming store identification
- High return-rate product analysis
- Promotion effectiveness tracking

## 📊 Dashboard
- Interactive Streamlit dashboard
- Dynamic filters
- KPI cards
- Heatmaps
- Product and customer insights

## 🔮 Forecasting
- Time-series forecasting using Prophet
- Trend and seasonality analysis
